# Atheory Homebrew Tap

Homebrew formulas for Atheory tools.

## Install Argent

Argent will be available from this tap when its first release is published.

```sh
brew tap atheory-ai/tap
brew install argent
argent version
```

## Install Skillex

```sh
brew tap atheory-ai/tap
brew install skillex
```

Upgrade installed tools with `brew upgrade argent` or `brew upgrade skillex`.
Formulae in this repository are maintained by the corresponding release workflows.
